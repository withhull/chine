Every externally visible statement about this repository must map to a row in
this table. Statements not in the "allowed" column are not made anywhere in
the code, output, or documentation.

Naming note (2026-11-22): the product was renamed Tuckmill → Chine
(TuckCore → ChineCore, `tuckmill-*` crates → `chine-*`, the `TUCKMILL_*`
environment variables → `CHINE_*`, the `tm_` native ABI prefix → `ch_`,
the data directory → `~/Library/Application Support/Chine`). Records,
benchmarks and commit history dated before the rename carry the old
names; they are unchanged as historical artifacts.
